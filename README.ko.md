## 설치

```bash
brew tap 132262b/hicapture && brew trust 132262b/hicapture && brew install --cask hicapture
```

[hi-capture.com](https://hi-capture.com) 에서 내려받을 수도 있습니다. macOS 14 이상이 필요합니다.

## 업데이트와 삭제

```bash
brew update && brew upgrade --cask hicapture
brew uninstall --cask hicapture
```

이 저장소에는 cask([Casks/hicapture.rb](Casks/hicapture.rb))와 릴리스 빌드가 있습니다.
